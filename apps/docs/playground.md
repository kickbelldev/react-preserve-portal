# 인터랙티브 예제

메모를 바꾸고 카운터를 올린 뒤 **미니로**를 눌러보세요. 플레이어를 새로 만드는 대신 같은 카드가 다른 Slot으로 이동합니다.

<PortalPlayground />

## 입력값과 React 상태 확인하기

메모는 React state로 관리하지 않는 입력값이고, 카운터는 React state입니다. 메인·미니 사이를 옮겨도 두 값이 유지됩니다. 카드의 이동 횟수 역시 카드 안의 React 상태로, 서로 다른 슬롯을 선택할 때 증가합니다.

이 구성을 앱에 붙여 넣으려면 [빠르게 시작하기](./guide/quick-start)를 참고하세요.

## 숨기기와 초기화 구분하기

**숨기기**나 **reset()**을 누른 뒤 **메인으로**를 누르세요. 이전 메모와 숫자가 돌아옵니다. `reset()`은 선택한 슬롯과 복귀 경로를 비우며 콘텐츠 내부 상태를 초기화하지 않습니다.

이 예제는 숨길 때 영상을 일시정지합니다. 다시 표시한 뒤 재생 버튼을 누르면 이어 볼 수 있습니다. 일시정지는 예제의 동작이며 포털 자체의 숨김 기능은 미디어를 제어하지 않습니다. [비디오 플레이어 가이드](./guide/video-player)에 전체 코드가 있습니다.

## 브라우저에 따라 달라지는 동작

카드는 같은 `<video>` 요소를 사용합니다. 연결된 Slot 사이에서 `moveBefore`로 옮기면 재생 상태를 보존할 수 있지만, `appendChild` 폴백이나 숨김·복귀에서는 멈출 수 있습니다.

상단의 표시는 **브라우저의 지원 여부**입니다. 지원 브라우저도 최초 연결과 숨김 후 복귀에는 분리된 노드를 붙이므로 `appendChild`를 사용합니다. 버튼을 클릭하면 포커스가 버튼으로 이동하므로, 이 조작 자체가 포커스 보존을 검사하는 방법은 아닙니다. 자세한 조건은 [보존 원리와 수명](./guide/preservation)을 참고하세요.

## 이동 애니메이션

기본으로 켜져 있는 **이동 애니메이션 (FLIP)** 은 브라우저 API 없이 직접 구현한 방식입니다. 옮기기 직전에 카드의 위치와 크기를 재고, 옮긴 뒤 같은 카드 요소를 이전 위치에서 새 위치로 미끄러지듯 움직입니다. 포털이 요소를 새로 만들지 않고 그대로 옮기기 때문에 이 방법이 가능하고, 움직이는 동안에도 영상은 계속 재생됩니다. 모든 브라우저에서 동작합니다.

View Transition은 브라우저가 제공하는 전환 효과로, 지원 브라우저에서만 켤 수 있습니다. 두 방식 중 하나만 켤 수 있고, 어느 쪽도 상태 보존에는 필요하지 않습니다. 모션 줄이기 설정이 켜져 있으면 애니메이션과 영상 자동 재생을 사용하지 않고, 설정을 켜는 즉시 재생 중인 영상도 일시정지합니다.

이 페이지를 벗어나면 Host가 언마운트되므로 다시 방문했을 때 새 콘텐츠가 생기는 것이 정상입니다. 구현은 [playground.tsx](https://github.com/kickbelldev/react-preserve-portal/blob/main/apps/docs/.vitepress/theme/playground.tsx)에서 볼 수 있습니다.
